# PDF font

`AetherSansSC-Regular.ttf` embeds Chinese text in exported reports. It is the regular-weight static instance of [Noto Sans SC](https://github.com/notofonts/noto-cjk/blob/main/Sans/Variable/TTF/Subset/NotoSansSC-VF.ttf), renamed Aether Sans SC. The upstream font uses the SIL Open Font License in `OFL.txt`.

Upstream Git blob SHA-1 is `5371a543be5fc670c7cdee9760c03554ee3e9b8e`. The static instance uses weight 400 and retains the original character coverage. PDF exports embed only the glyphs they use. Font processing is performed when preparing this asset and requires no runtime download.
