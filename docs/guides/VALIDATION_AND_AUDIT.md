# Evidence, evaluation and audit boundaries

Facts in current answers/reports require saved eligible evidence. Numeric fields and units are checked mechanically. A separate-context Pro reviewer assesses source support, ambiguity and scope, selecting exact saved source fragments. This is inspectable AI review, not publisher truth or guaranteed correct reasoning. Unsupported claims are revised/removed; failed drafts remain private.

New analyst reports include local evidence packages with referenced records, originals, recipes, review output, config, source snapshot and environment locks. Hashes detect changes; they do not authenticate a historical public release date. Private portfolio citations add private records to a local export. Keys and account secrets are excluded.

```bash
python scripts/audit/replay_bundle.py data/audit/PACKAGE_ID --execute-recipes
```

Without `--execute-recipes`, saved Python is not executed. Replay uses saved inputs without model/network calls. Running archived code is local host execution, so inspect packages you did not create. Successful replay proves numeric reproducibility under the installed implementation, not method suitability or future investment skill.

## Historical evaluation

```bash
python scripts/evaluation/evaluate_history.py --cases 12 --workers 2
```

This optional evaluation needs a prepared archive and configured model. It separates chronological development/validation/test cases and future horizons. Current network, terminal and shared memory are unavailable in the frozen harness; source cutoff checks refuse future records. LLM training memory can still contain hindsight, and unknown publication dates limit strict point-in-time claims.

Citation coverage, numerical correctness, unsupported/contradicted claims, failures and forecast abstention are separate metrics. Small pilot samples do not establish statistical accuracy or profitability. The Strategy Lab is a distinct local statistical experiment, with purged labels, expanding refits and cost-aware baselines; see [investment methods](../architecture/INVESTMENT_COMPONENTS.md).

## Evidence memory and advice evaluation

The newer [memory evaluation](MEMORY_EVALUATION.md) adds thirteen official-source
snapshots/twelve topic groups, prewritten short-passage labels,39 retrieval/time
probes, six matched selector/ablation variants,77 frozen offline contract checks
and a twelve-output paired Pro answer pilot. Source, code and test digests are
frozen. A disposable source-tree replay avoids changing the running application.
Weaker selector results and response-label disagreements are retained.

Mechanical source/quote integrity, AI-authored answer-mode labels, separate
source-review assessments and independent human semantic truth are different
things. Exact quote matches are not answer correctness. Human adjudication and
twelve real multi-version event histories remain gaps; the inspected corpus is
not an untouched confirmation set for subsequent tuning. No investment edge is
established by any of these tests.

Advice now has source-linked rationale, conditions, counterpoints, invalidation,
review triggers and optional qualified historical cases. Validators check
numeric fields/units, actual vs unknown personal context, case end, receipts and
input lineage. Old reports stay compatible. Separate source review still checks
the prose. A real current-data/search/report run and a saved-experiment history
answer passed this path; rejected drafts remain available. This is a bounded
integration result, not a measured general recommendation accuracy rate.

## Optional public audit anchoring

`contracts/` and `scripts/audit/` retain a Sepolia-only hash-anchor design, with optional dependencies in `requirements.audit.*`. Local EVM tests and a readable deployment client are not proof of a public deployment. The core product does not require testnet funds, deploy a contract, submit a transaction or expose private keys.

A chain receipt, when separately obtained and verified, can establish that file digests match a particular public registration. It cannot establish source truth, historical availability, investment suitability or future returns. No production-chain action is implied by preparing this repository.
