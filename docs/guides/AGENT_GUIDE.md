# Harness and flexible tools

The product uses local LangChain Deep Agents / LangGraph with Doubao Pro, not a developer assistant's tool loop. Session skills describe source selection, chronology, analysis and uncertainty. They do not force every research question through the same data checklist.

Optional data adapters coexist with public API exploration, web search, original page capture and real local terminal/Python. The model can inspect data schemas, write a custom method and register a rerunnable calculation with source IDs, numeric fields and units. Registered calculations are reproducibility receipts, not endorsements of the chosen method.

The current model-visible investment tool reads a private manual portfolio snapshot. Strategy experiments and position previews are available through the terminal SDK and product APIs, rather than extra default model tools. Jev remains an optional product adapter, not a default analyst tool. These paths do not write ledger transactions or send exchange orders; historical research cannot access current/private services. See the exact current interface in [HARNESS](../architecture/HARNESS.md).

Current answers and reports pass through eligible-citation, numeric/unit and separate-context source-support checks. Source material and external instructions remain untrusted data. See [architecture](../architecture/OVERVIEW.md), [usage](PRODUCT_GUIDE.md) and [local permissions](../../SECURITY.md).

The legacy conversation bridge is only for deterministic harness/debug testing. Its no-API stub is not used as a substitute for the configured product model.
