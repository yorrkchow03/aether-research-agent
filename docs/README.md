## Verification and handoff

- [Testing](development/TESTING.md): offline checks and explicit live experiments.
- [Repository boundary](development/REPOSITORY.md): shared source versus private state.
- [Conditional-research acceptance](development/CONDITIONAL_RESEARCH_ACCEPTANCE.md):
  the latest report/case-memory change and its limitations.
- [Report-flow confirmation](development/REPORT_CONFIRMATION.md): all fixed
  attempts, failures, recovery and independent AI assessments.

Other plans, assessments and acceptance notes under `development/` are dated
research records. Read their scope and date before treating a historical result
as the current implementation or an independently verified accuracy claim.
