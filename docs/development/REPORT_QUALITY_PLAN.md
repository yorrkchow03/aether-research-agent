# Investor research report quality

Authorized 2026-10-28. Improve the existing research product so investors can
understand important developments, inspect sources and form their own judgment.
Conditional suggestions remain optional. Price prediction, strategy returns,
all-metric coverage and whole-corpus Jev classification are outside this round.

## Acceptance

1. Ordinary reports can be informational without a buy/wait/avoid decision,
   optional forecast or simulated strategy. Every new sourced key-change claim
   enters the same numeric, review, citation, replay and export checks.
2. Important event assertions expose publication/capture clocks, later related
   evidence, conflicts and missing verification. A newer document is not
   automatically true or a confirmed cancellation of a different dated plan.
   Strict historical mode excludes later-acquired sources and relationships.
3. Readers can flag an unclear/outdated/unsupported report statement. Saved
   user feedback remains an allegation until reviewed. Source-backed review and
   correction receipts link the original claim, sources and a corrected report;
   old content remains readable. Correction experience is dated and does not
   become a trading law or human ground truth.
4. Evaluate source faithfulness, event/date distinctions, numerical consistency,
   required qualifications, conditional suggestions, readability and costs.
   Separate programmatic checks from independent model judgments. Small known
   regressions do not establish broad semantic accuracy or causal improvement.
5. One bounded real report uses the local business harness and configured
   Doubao Pro/Agent Plan. The independent Terra reviewer only reads saved
   report/evidence artifacts. Preserve original attempts, unknown usage and
   abstention; at most18 initial author responses, one targeted continuation of
   at most8 if an actual fix is needed, at most2 source-review responses per
   acceptance job. No blind repeated report campaign.
6. Desktop/mobile source/report/feedback workflow and clean source export pass;
   optional memory/Jev failures do not stop unrelated research. No new business
   tools, harness/model/endpoint changes, data purchases, trading, Git push,
   public upload or new recurring schedule.

## Confirmed starting issue

Independent review found that the half-year note omitted an available October22
official Hoodi postponement while treating an older roadmap's October27 date as
the next concrete checkpoint. The postponement concerned the previously planned
October26 event; it does not by itself prove cancellation of October27. Preserve
this precision in notices, memory, regression labels and any revised report.
Other possible issues include causal language inferred from correlation and an
undefined future update window for a fixed historical ETF total. These are
review findings, not certified manual labels.

Start with offline checks and bounded source fixtures. Run actual Pro only after
integration passes; do not recollect the half-year library or repeat old studies.
