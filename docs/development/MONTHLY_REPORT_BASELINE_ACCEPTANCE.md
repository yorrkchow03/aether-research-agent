six completed mechanical score sets from the exact same scorer/source bytes and
preserves both original failures,with 0 model/data-network calls. Frozen files

coverage checks separately from human semantic judgments.

See [baseline guide](../guides/MONTHLY_REPORT_BASELINE.md) for new unique runs,
existing-state inspection,offline replay and the human review template. A future
Jev comparison must use identical questions/material/time/context conditions
within each pair. This supplied-context pilot is not a retrieval-recall study,
a profitability backtest or an untouched statistically powered benchmark.
