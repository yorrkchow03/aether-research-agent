# Monthly report baseline plan

This is a new report-quality task after the usable monthly-library v4 delivery.
Missing required source rights remain recorded; this work does not resolve or
relabel that earlier core coverage. No new schedule, purchase, order or Jev call.

1. Freeze the eight predeclared diagnostic questions in
   examples/evaluation/monthly_report_cases_v1.json and materialize eligible
   source records from immutable v4 with original hashes and acquisition times.
2. Run one real product report through the existing local Deep Agents/Doubao Pro
   terminal, SDK, planning and publication gate. Preserve all failures, drafts,
   reviews, events, latency and author/reviewer usage. This is a workflow smoke,
   not a fair comparison with the isolated fixed-context study.
3. Run all eight fixed-context report cases with the same Pro/Plan model and
   Deep Agents harness. Only selected captured inputs and a structured draft
   submission capability are available; no network data, terminal, shared memory,
   Jev or outcome tools. Model transport is allowed. Record first submissions
   without correctness-driven repair or cherry-picking.
4. Check source IDs, exact numeric fields/units, expected numeric coverage and
   strict acquisition cutoff deterministically. Retain predeclared response-mode
   agreement separately. Semantic rationale/correction/advice labels are
   provisional and require human review; product AI review is not ground truth.
5. Deliver reports, traceable check results and a reusable review template,
   recording common denominators, failures/abstentions,latency and token usage.
   Subscription dollar cost is unknown; do not convert tokens into fictitious fees.

This is a small diagnostic pilot without statistical/generalization or investment
performance claims. User test examples and future Jev comparisons must preserve
identical questions, source bytes and context conditions. No large model training.
